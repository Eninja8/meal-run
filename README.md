# Meal Run

Food & Beverage tool for served meal events: tap-count each table's meals, combine tables into serving runs, and give the kitchen one total per run.

- **Tables**: pick a table, tap a meal to add one, tap − to take one back.
- **Runs**: select tables, make a run. Shows cart fit (default 24) and can suggest runs.
- **Kitchen**: big-print totals per run, remaining, event total, and a table sheet.
- **Setup**: events, meal types (standard and special), tables, cart capacity.

Everything is saved on the device. Works offline after the first load.

Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
